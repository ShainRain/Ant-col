# Ant-col 蚁穴 · 本地视觉收件箱

> 把浏览时看到的图片、截图、链接和灵感，3 秒收进自己的项目；  
> 收完能整理，过很久还能找回来，最后能拿去用。

Ant-col 蚁穴是一个**完全本地**的个人视觉素材工具：浏览器扩展负责采集，独立素材库页面负责整理、搜索和交付。不依赖任何外部客户端、不需要账号、不上传任何内容。

---

## 为什么需要它

收藏图片本身不难，难的是三件事：

1. **收得顺**：不打断浏览，不先下载再翻文件夹；
2. **找得回**：过一个月还能按来源、项目、标签想起它；
3. **用得上**：素材能进入设计、开发或提案，而不是死在 Downloads。

Ant-col 蚁穴围绕这三件事组织：

```
采集 Capture → 收件箱 Inbox → 整理 Triage → 找回 Recall → 交付 Handoff
```

## 功能

### 采集

- 拖拽网页里的图片、视频、链接：弹出收藏页，直接选项目；
- 悬停保存：`Alt+S`；
- 批量扫描当前页：工具栏图标，支持尺寸过滤、CSS 背景图、视频封面；
- 截图：可见区域 / 框选元素 / 整页滚动拼接；
- 链接卡片：保存为可打开的 `.html` 卡片；
- 自动去重：按「内容 + 项目」的 SHA-256，同一张图可以进不同项目。

### 收件箱 Inbox

- 新采集默认进入 **Inbox**；
- 逐张整理：`K` 保留、`A` 归档、`→` 跳过、`Esc` 退出；
- 批量移动项目、加标签、标记已整理、归档；
- 工具栏徽标显示待整理数量。

### 素材库 Library

独立页面（不是 popup）：

- 左侧：Inbox / 全部 / 已整理 / 归档 / 项目 / 标签；
- 顶部：搜索、类型筛选、排序；
- 网格：缩略图、项目、类型、尺寸、状态；
- 详情抽屉：预览、项目、状态、标签、备注、路径、来源；
- 批量操作与导出。

搜索支持：

```
tag:海报  project:日常审美  site:xiaohongshu
kind:image  is:inbox  after:2026-09-01
```

（`after:` 目前作为普通文本匹配，后续可升级为日期语法。）

### 交付 Handoff

- 复制文件路径；
- 定位文件 / 打开来源；
- 导出 Markdown / CSV；
- 导出当前筛选结果，或只导出选中项。

### 本地优先

- 原图、同名 JSON、`_index.json` 都在你的文件夹里；
- 缩略图缓存在浏览器 IndexedDB，可重建；
- 无云端、无遥测、无第三方接口依赖；
- 项目归类写入索引与 sidecar，文件路径不强制搬动。

## 安装

1. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）；
2. 开启「开发人员模式」；
3. 点「加载解压缩的扩展」，选择本目录 `shitu-vault`；
4. 固定工具栏图标，打开设置选择一个素材库文件夹；
5. 点设置页或 popup 里的「打开素材库」。

不选文件夹也能用，默认保存到：

```
下载 / Ant-col素材
```

建议新建独立文件夹，例如：

```
C:\Users\ShainRain\Pictures\Ant-col素材
```

文件夹授权在浏览器重启后可能需要重新确认一次，设置页会提示。

## 使用流程

### 1. 采集

拖动网页里的图片/链接，页面中央出现收藏页：

- 左侧：`拖拽到这里添加到 <项目>`；
- 右侧：项目列表；
- 底部：`＋ 建立或选择文件夹`。

拖到左侧或某个项目上松开，进入保存面板：

- 改名称；
- 加标签、备注；
- 选择图片 / 链接卡片；
- 保存到项目。

### 2. 整理

打开素材库 → Inbox：

- 点「整理 Inbox」逐张处理；
- 或勾选多张，用底部批量栏移动项目、加标签、标记已整理、归档。

### 3. 找回

- 左侧按项目/标签浏览；
- 顶部搜索名称、来源、页面标题、备注、标签；
- 类型筛选 + 排序；
- 详情里查看来源、尺寸、路径、备注。

### 4. 交付

- 详情里复制路径 / 定位文件 / 打开来源；
- 顶部导出 Markdown 或 CSV；
- 导出只包含当前筛选结果；有选中项时只导出选中项。

## 快捷键

| 快捷键 | 动作 |
| --- | --- |
| `Alt+S` | 保存鼠标悬停的图片 / 视频 |
| `Alt+Shift+S` | 可见区域截图 |
| `Alt+Shift+E` | 框选元素截图 |
| `Alt+Shift+F` | 整页截图 |
| `/` | 在素材库聚焦搜索 |
| `K` / `A` / `→` / `Esc` | Inbox 整理：保留 / 归档 / 跳过 / 退出 |

批量保存走工具栏图标或右键菜单。快捷键可在 `edge://extensions/shortcuts` 修改。

## 保存结构

默认项目「灵感收集」不额外建目录；其他项目会建同名子文件夹。

```
Ant-col素材/
├── 图片/2026-10/
│   ├── 20261019_123000_local_art-1.jpg
│   └── 20261019_123000_local_art-1.json
├── 日常审美/
│   └── 图片/2026-10/
├── 截图/2026-10/
├── 链接/2026-10/
├── 视频/2026-10/
└── _index.json          # 文件夹模式下的索引镜像
```

每条素材都有同名 JSON：

```json
{
  "schema": "shitu/v2",
  "id": "MVERBOKECCVUY",
  "kind": "image",
  "name": "art-1",
  "collection": "日常审美",
  "collectionPath": "日常审美",
  "status": "inbox",
  "tags": ["unsplash", "抽象"],
  "annotation": "为什么存它",
  "sourceUrl": "https://...",
  "pageUrl": "https://...",
  "width": 1600,
  "height": 1000,
  "savedAt": "2026-10-19T12:30:00.000Z",
  "relativePath": "日常审美/图片/2026-10/....jpg"
}
```

`status` 取值：`inbox` / `kept` / `archived`。

## 设置

- **保存位置**：自动 / 仅素材库文件夹 / 仅下载目录；
- **下载子文件夹**：下载模式下的根目录名；
- **文件名模板**：`{date}_{time}_{site}_{name}_{month}`；
- **项目**：逗号分隔，第一个为默认项目；
- **扫描尺寸 / 截图格式 / 去重 / sidecar / 自动标签 / CSS 背景图 / Referer**；
- **素材库入口、导出索引、清空索引**。

项目归类只更新素材库索引与 sidecar，不会强行移动已保存文件；文件路径仍以详情里显示的为准。

## 已知限制

- 页面内拖拽；从其他窗口/桌面拖入暂未接入；
- 文件夹模式重启后可能需要重新授权；
- 项目归类是元数据变更，不移动已有文件；
- 视频、链接没有自动缩略图，显示类型占位；
- 旧版素材没有缩略图缓存时，会尝试用来源 URL 或占位图；
- 没有云同步、社交、移动端；
- 搜索暂不支持颜色/日期语法，`after:` 仍是文本。

---

## 设计原则

1. **采集不打断浏览**；
2. **先收再整理，不强迫当场分类**；
3. **文件是真相，索引可重建**；
4. **本地优先，数据可迁移**；
5. **先让素材找得回，再谈智能**。
